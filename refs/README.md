# refs/

Reference books used during engine development. **Not committed** to git (large binaries, copyright). Treat as read-only local material.

## Current contents (expected)

- *Real-Time Rendering, 4th Edition* — Akenine-Möller, Haines, Hoffman. EPUB.
- *Physically Based Rendering: From Theory to Implementation* — Pharr, Humphreys. EPUB.
- *Fundamentals of Computer Graphics* — Marschner, Shirley. EPUB.
- *Computer Graphics: Principles and Practice, 3rd Edition* — Hughes, van Dam, McGuire, et al. PDF.

## Usage

These books inform the research notes in `research/`. The notes contain summaries and engine-implementation implications; the source books are the ground truth for anything not in the notes.
